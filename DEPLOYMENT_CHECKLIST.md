## 📋 Deployment Steps

### 1. Backend Deployment (Railway/Render)

#### Option A: Railway (Recommended)

1. **Create Railway Account**
   - Visit [railway.app](https://railway.app)
   - Sign up with GitHub

2. **Create New Project**
   ```bash
   # From Railway Dashboard:
   - Click "New Project"
   - Select "Deploy from GitHub repo"
   - Choose your repository
   - Set root directory to: /
   ```

3. **Add PostgreSQL Database**
   ```bash
   - Click "New" → "Database" → "PostgreSQL"
   - Railway will auto-generate DATABASE_URL
   ```

4. **Configure Environment Variables**
   ```env
   DATABASE_URL=<auto-generated-by-railway>
   JWT_SECRET=<generate-strong-32-char-secret>
   NODE_ENV=production
   PORT=3000
   ```

5. **Configure Build Settings**
   ```json
   Build Command: npm install && npx prisma generate && npm run build
   Start Command: npm start
   ```

6. **Run Database Migrations**
   ```bash
   # In Railway console or locally:
   npx prisma migrate deploy
   npx prisma db seed  # Optional: seed initial data
   ```

7. **Get Your Backend URL**
   - Railway will provide: `https://your-app.up.railway.app`
   - Or configure custom domain: `takatrack.dupno.com`

#### Option B: Render

1. **Create Render Account**
   - Visit [render.com](https://render.com)

2. **Create Web Service**
   ```bash
   - New → Web Service
   - Connect GitHub repository
   - Name: taka-track-api
   - Environment: Node
   - Build Command: npm install && npx prisma generate && npm run build
   - Start Command: npm start
   ```

3. **Add PostgreSQL Database**
   ```bash
   - New → PostgreSQL
   - Copy connection string
   ```

4. **Environment Variables**
   ```env
   DATABASE_URL=<postgres-connection-string>
   JWT_SECRET=<your-secret-key>
   NODE_ENV=production
   PORT=3000
   ```

### 2. Frontend Deployment (Vercel)

1. **Create Vercel Account**
   - Visit [vercel.com](https://vercel.com)
   - Sign up with GitHub

2. **Import Project**
   ```bash
   - Click "Add New" → "Project"
   - Import your GitHub repository
   - Framework Preset: Vite
   - Root Directory: client
   ```

3. **Configure Build Settings**
   ```bash
   Build Command: npm run build
   Output Directory: dist
   Install Command: npm install
   ```

4. **Environment Variables**
   ```env
   VITE_API_URL=https://your-backend-url.railway.app/api/v1
   ```
   (Or use the `.env.production` file already configured)

5. **Deploy**
   - Click "Deploy"
   - Vercel will auto-deploy on every push to main

6. **Custom Domain (Optional)**
   ```bash
   - Go to Project Settings → Domains
   - Add: takatrack.dupno.com
   - Configure DNS as instructed
   ```

## 🔧 Post-Deployment Configuration

### 1. Update CORS Settings

In `src/app.ts`, ensure CORS allows your frontend domain:

```typescript
app.use(cors({
  origin: [
    'http://localhost:5173',
    'https://takatrack.dupno.com',
    'https://your-vercel-domain.vercel.app'
  ],
  credentials: true
}));
```

### 2. Test API Endpoints

```bash
# Health check
curl https://your-backend-url.railway.app/

# Test auth
curl -X POST https://your-backend-url.railway.app/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{"email":"test@example.com","password":"test123"}'
```

### 3. Verify Database Connection

```bash
# In Railway/Render console:
npx prisma studio  # Opens database GUI
```
